Flagship Project

ContextChat

// the app you're looking at right now

ContextChat started from a simple frustration: every "AI assistant" sends your data to a cloud you don't control. I wanted something that runs entirely on my own hardware — memory, search, voice, and all — with zero subscriptions and zero data leakage.

Built with Electron + React + TypeScript, it embeds a local vector database (LanceDB), runs Whisper for on-device speech-to-text, supports Ollama models out of the box, and lets you plug in OpenAI or Anthropic keys if you prefer hosted inference. The Knowledge Base feature lets you drop in PDFs and notes and query them in plain English — locally, always.

Philosophy

Local-first. If the data is yours, it should stay on your machine. Not because the cloud is evil, but because you shouldn't need to trust a third party to use your own AI.

Build to ship. A working v0.1 beats a perfect v0-never. ContextChat started as a weekend project — the best features came from actually using it, not from planning them upfront.

Open by default. No vendor lock-in. Use Ollama, or OpenAI, or Anthropic. Swap models. If I build something useful, it should be forkable.
