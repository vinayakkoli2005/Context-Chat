How It Works

01

Install & Run

Download the installer. Runs silently in your system tray. No setup wizard, no account required.

02

Select Anything

Highlight text anywhere on your screen — a bug, an email, a document. A floating icon appears.

03

Get a Cited Answer

Click it. The AI responds instantly — pulling from your files and citing exactly which one it used, so you can trust and verify every reply.
