📦 Installing Ollama

Ollama is the local AI runtime that powers ContextChat. It runs entirely on your machine — no account, no cloud.

1

Download Ollama

Go to ollama.com and download the Windows installer. It's a simple .exe — run it and follow the prompts.

2

Verify installation

Open a terminal (PowerShell or CMD) and run:

ollama --version

You should see a version number like ollama version 0.x.x. If you get "command not found", restart your terminal or reinstall.

3

Ollama not downloading?

If the installer won't download or run, try these alternatives:

# Option A: via winget (Windows Package Manager) winget install Ollama.Ollama # Option B: via Chocolatey choco install ollama
ℹ️ Ollama runs best with a GPU (NVIDIA or AMD). On CPU-only machines it still works — just slower. 8GB RAM minimum recommended.

▶️ Running Ollama

ContextChat needs Ollama's API server to be running. Here's how to start it.

1

Start the Ollama server

Open PowerShell and run:

ollama serve

You'll see output like Listening on 127.0.0.1:11434. Keep this terminal open — closing it stops Ollama.

2

Verify it's working

In a new terminal, run:

curl http://localhost:11434/api/tags

You should get a JSON response. If you get "connection refused", Ollama isn't running.

3

Already running?

If Ollama was installed via the desktop app, it may already be running in your system tray. Look for the Ollama icon in the bottom-right corner of your taskbar. If it's there, you don't need to run ollama serve manually.

🔄 Keep Ollama Running Permanently

Don't want to manually start Ollama every time? Set it up to run automatically on Windows startup.

⚡ Option A — Windows Task Scheduler (Recommended)

Open PowerShell as Administrator and run:

$action = New-ScheduledTaskAction -Execute "ollama" -Argument "serve" $trigger = New-ScheduledTaskTrigger -AtLogOn $settings = New-ScheduledTaskSettingsSet -Hidden Register-ScheduledTask -TaskName "OllamaServe" -Action $action -Trigger $trigger -Settings $settings -RunLevel Highest

Ollama will now start automatically every time you log in to Windows.

🖥️ Option B — Ollama Desktop App (Easiest)

If you installed Ollama via the desktop installer, it already added itself to Windows startup. Check:

  • Press Win + R, type shell:startup, press Enter
  • You should see Ollama listed there
  • If not, right-click the Ollama tray icon → "Launch at startup"

🔧 Option C — Windows Service (Advanced)

For power users who want Ollama running even before login:

# Install NSSM (Non-Sucking Service Manager) winget install nssm # Create Ollama as a Windows service nssm install Ollama "C:\Users\%USERNAME%\AppData\Local\Programs\Ollama\ollama.exe" serve nssm start Ollama

⬇️ Downloading Models

ContextChat needs at least one chat model and one embedding model. Here's what to download.

1

Pull a chat model

For most machines (8GB+ RAM):

ollama pull llama3.2

For lower-end machines (4GB RAM):

ollama pull llama3.2:1b

For vision (screenshots):

ollama pull llava
2

Pull the embedding model (required for Memory + Knowledge Base)

ollama pull nomic-embed-text

This is a small model (~270MB) used to power persistent memory and the knowledge base. Without it, those features won't work.

3

Check what's installed

ollama list

Shows all downloaded models with their sizes.

⚠️ Models are large files (1–8GB each). Make sure you have enough disk space before pulling. They're stored in C:\Users\[you]\.ollama\models\.

💾 Installing ContextChat

1

Download the installer

Download ContextChat-Setup.exe from the releases page and run it.

2

First launch

ContextChat appears in your system tray (bottom-right). The setup wizard will open automatically — enter your Ollama URL (http://localhost:11434) and select a model.

3

Test it

Select any text on your screen. A small floating icon appears — click it. The AI panel opens and responds. That's it.

✅ Shortcut: Ctrl+Shift+Space opens the panel from clipboard. Ctrl+Shift+V opens voice input.

🔑 Using OpenAI or Anthropic Instead

Don't want to run Ollama locally? You can use cloud providers instead — just add your API key.

1

Open the Dashboard

Right-click the ContextChat tray icon → Dashboard → Setup tab.

2

Enter your API key

Paste your OpenAI key (starts with sk-...) or Anthropic key (starts with sk-ant-...). Keys are stored locally — never sent anywhere except to that provider's API.

3

Select provider in Models tab

Switch provider to OpenAI or Anthropic and pick a model. ContextChat will use that for all future chats.

⚠️ Memory and Knowledge Base still require Ollama + nomic-embed-text for embeddings, even when using OpenAI/Anthropic for chat.

📚 Setting Up the Knowledge Base

1

Make sure nomic-embed-text is installed

ollama pull nomic-embed-text
2

Open the Knowledge Base tab

Dashboard → Knowledge Base tab. Drag and drop .txt, .md, or .pdf files onto the drop zone.

3

Wait for indexing

Files are chunked and embedded locally. A spinner shows while indexing. Large PDFs may take 30–60 seconds.

4

Start chatting

Every message now automatically searches your documents. Relevant chunks are injected as context and the source file is cited at the bottom of the AI's reply.

🔧 Troubleshooting

❌ "Ollama is not running" error in ContextChat

  • Open PowerShell and run ollama serve
  • Check the tray icon — Ollama may have crashed
  • Verify with curl http://localhost:11434/api/tags
  • If port 11434 is in use: netstat -ano | findstr 11434 then kill the conflicting process

❌ No memories appearing

  • Make sure nomic-embed-text is installed: ollama pull nomic-embed-text
  • You need at least 2 user messages in a conversation before memories are extracted
  • Memories are extracted when you close the panel — not during the conversation

❌ Knowledge Base indexing fails

  • Ollama must be running with nomic-embed-text available
  • Check the file isn't password-protected (PDFs)
  • File must be at least 10 words long to be indexed
  • Try a plain .txt file first to confirm the pipeline works

❌ AI responses are very slow

  • Switch to a smaller model: ollama pull llama3.2:1b
  • Close other GPU-heavy applications
  • Check RAM — models need to fully load into memory
  • Consider using OpenAI/Anthropic API for faster responses

❌ Floating icon doesn't appear when selecting text

  • Make sure ContextChat is running in the system tray
  • Try the keyboard shortcut: select text, wait 0.5s — if icon still doesn't appear, restart the app
  • Some apps (games, full-screen apps) block selection detection — use Ctrl+Shift+Space with clipboard instead

❌ Voice input not working

  • Microphone permissions must be granted to ContextChat in Windows Settings → Privacy → Microphone
  • The Whisper model downloads automatically on first use (~150MB) — wait for it to finish
  • Check your default microphone in Windows Sound settings
